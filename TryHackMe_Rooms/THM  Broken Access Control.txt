1. What is access Control?
Access control is a security mechanism used to control which users or systems are allowed to access a particular resource or system.

2.Access control Mechanisms : 
i) Discretionary Access Control
ii) Mandatory Access Control
iii) Role-Based Access Control
iv) Attribute Based Access Control


3. Vertical and Horizontal Privilege escalation

4. IDOR - Insecure Direct Object Reference
5. Horizontal Privilege escalation occurs when an attacker can access resources or data belonging to other users with the same level of access levels
6. Vertical Privilege Escalation occurs when an attacker can access resources or data from users with higher access levels
7.ABAC - Attribute Based Access Control
8.RBAC - Role Based Access Coontrol
